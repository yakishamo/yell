# yell

## 概要
簡易シェルの実装です。外部コマンド実行、パイプ、リダイレクト、組み込みコマンドなどを実装しています。

## ビルド方法
make

## 実行方法
./yell

## 実装した機能
- 外部コマンド実行
- パイプ
- 入出力リダイレクト
- cd
- exit
- エラー処理

## テスト例
ls  
echo hello  
echo hello > out  
cat < out  
echo hello | cat  
cat nonexistent  
echo hoge >  

## 工夫した点
- fork後の子プロセスでは _exit() を使用し、親プロセス側の状態に影響を与えないようにした
- リダイレクト時のファイルディスクリプタ操作を、子プロセス側に閉じ込めた
- パイプライン実行時に不要なfdを閉じ、デッドロックや資源リークを避けるようにした
- 構文エラーやopen失敗などを検出し、異常終了しないようにした

## 既知の制限
- クォートやエスケープの完全対応はしていない
- ジョブ制御は未実装
- Bash互換を完全に目指したものではない
